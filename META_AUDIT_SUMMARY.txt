## What Went Wrong

The validation framework does NOT test the application. It tests itself with:

1. **Synthetic workloads** - random bytes, no real audio processing
2. **Hardcoded values** - confidence, drift metrics all hardcoded  
3. **Assumed verification** - "trust me, circuit breaker works" without testing
4. **No real services** - asyncio.sleep() replaces actual TTS, emotion, translation

**Example Problem:**
- Test reports: p99 latency = 420ms ✓ (meets SLA)
- Reality: p99 latency = ~2000ms with real services (FAILS SLA)
- Root cause: Latency measured only on fake asyncio.sleep(), not real inference
